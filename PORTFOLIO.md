Python Sales Report Automation: CSV Cleaning and Excel Dashboard

## Suggested role

Python Automation and Excel Reporting Developer

## Upwork portfolio description

Built a beginner-friendly Python automation tool that converts raw sales CSV data into a polished Excel report. The workflow cleans duplicate and incomplete records, validates dates, quantities and prices, calculates revenue and business KPIs, and keeps rejected rows visible for review. The workbook includes a summary dashboard, product performance, monthly trends and Excel charts. Created as a portfolio demonstration using Python, pandas and XlsxWriter.
